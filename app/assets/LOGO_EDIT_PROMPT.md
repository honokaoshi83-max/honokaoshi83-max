# 透明 Logo

使用内置 image_gen 编辑用户提供的 app-logo.jpg。成品 app-logo.png 为 RGBA，外围背景透明；app-icon.ico 由成品转换为 Windows 多尺寸图标。原图保留。

最终提示词：

Edit the supplied logo image. ONLY remove the solid black exterior background outside the rounded-square illustrated icon and replace that exterior with true alpha transparency. Preserve the entire existing rounded white and pale-blue tile, character, headset, cyan speech bubble, blue ribbons, checkerboard, star highlights and every interior detail exactly as supplied. Do not redesign, repaint, add, remove, relight or alter the character or graphics. Keep the same centered square composition, scale and proportions. The smooth rounded outer contour must be cleanly antialiased with no black fringe, no black corners, no black border, no new shadow. The result is the same icon on a genuinely transparent background, ready for a light-blue desktop interface.
