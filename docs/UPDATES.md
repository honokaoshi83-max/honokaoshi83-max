# 应用内检查更新与旧版引导补丁

0.2.6新增应用内“检查更新”，入口位于左侧栏下方，也可从托盘菜单打开。首页原有模块和播报逻辑保留。

## 首次让旧版获得更新入口

0.2.4和0.2.5没有更新入口。先从托盘退出旧版界面，运行对应版本的小型更新器，选择原安装目录，即可升级到0.2.6并获得更新入口。无需重装模型或Python环境。引导补丁不能用于尚未安装程序的新设备。

更新器先核对版本、文件哈希和更新范围，再备份及替换文件。原有个人配置、按键、音量、自定义音色和缓存保留。已有程序文件被自行修改时会停止，不直接覆盖。写入失败时自动恢复本次修改；若磁盘或权限故障导致恢复也失败，会给出备份位置。

## 后续应用内更新

1. 点击“检查更新”，从本项目GitHub最新正式发布读取版本和说明。检查按需发起，不在驾驶中自动下载或更新。
2. 有适用于当前版本的增量包时，显示下载大小和“下载并更新”。只有完整安装包时提供发布页入口，不自动下载数GB资源。
3. 点击更新，下载后核对GitHub返回的SHA-256和文件大小。校验通过才启动更新器并退出当前界面；进入驾驶会话或存在未完成任务时不能启动更新。
4. 更新器暂停本目录后台，备份并更新程序；此前运行的后台会尝试恢复。完成后可以重新打开界面。原来处于停止状态的播报不会被擅自启动。

应用内更新只使用固定项目的HTTPS发布地址。发布者需要为每个支持的旧版本提供名称为`iracing-chinese-assistant-目标版本-update-from-旧版本.exe`的附件；缺少附件或校验信息时不会执行更新。

更新备份位于安装目录`.updates/日期-标识/`；下载缓存位于`.updates/downloads/`。Inno更新器可用`/LOG=日志路径`保存安装日志；完整程序日志入口仍是“诊断日志”。

## 构建

先准备两个已校验的完整离线payload，再运行：

```powershell
python scripts/build_delta.py 旧版payload 新版payload 补丁工作目录
ISCC /DPatchDir=补丁工作目录 /DFromVersion=0.2.4 /DToVersion=0.2.6 /DOutputDir=输出目录 scripts/update-setup.iss
```

依赖、基础模型或Python/PyTorch版本发生变化时，构建工具拒绝生成轻量补丁，改用完整安装。应用更新器不会更新Simulator Controller上游程序或改变其数据共享选择。

自动测试及独立目录更新不能替代另一台设备的安装和实际更新验收。本地开发版本未发布到GitHub时，检查页不会将它当作在线正式更新提供给其他用户。
