# 0.2.7 安装版更新

构建日期：2026-10-16。将此前0.2.6源码及本机修改汇总为新的安装版本，版本号用于区分旧测试包和应用内升级。

- 包含最近一次正赛／Time Trial复盘、真实时间与用时、正赛排名、提前退出延迟复盘和动态评价区域。
- 复盘显示波动率及简短括号规则，括号内容不朗读；语音与文本共用稳定性及趋势规则。
- 修复播报键请求丢失与繁忙堵塞，保留独立监听、驱动异常恢复、单次触发和防重复。
- 快车与左右并排等安全提醒优先于手动摘要，可以打断摘要及确认音；普通信息不能借用安全优先级。
- 包含默认关闭的“赛事策略（测试中）”独立页面和手动联网检查更新。
- 完整安装包含Python、CPU PyTorch、GPT-SoVITS、基础模型及默认双音色；Simulator Controller通过联网引导安装。
- 提供0.2.4、0.2.5及原始0.2.6安装构建到0.2.7的增量补丁。已经手动修改程序文件的目录会被更新器保护性拒绝，不强行覆盖。

原功能详情见[0.2.6源码说明](CHANGELOG_0.2.6.md)。自动测试、隔离目录安装与升级不能替代其他设备、实体按键、实际听感和完整比赛验收。
