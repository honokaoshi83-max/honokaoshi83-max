# 本地 CPU 性能说明

当前推理后端使用 CPU 版 PyTorch，并将计算线程设为 4。两角色共用一个串行切换的引擎。核心数翻倍不会使单句合成时间自动减半。

以 Ryzen 7 9700X 为使用基准：5600、12400 等六核 CPU 预计可运行基础播报，长摘要等待更明显；7600、9600X 预计接近基准，但游戏与语音同时运行的余量较少。9800X3D 的游戏优势不能直接当作语音合成速度提升。9900X、9950X 更多核心主要增加多任务余量，单句延迟提升仍须实测。

以上为部署预估，尚无这些 CPU 运行本项目的同条件实测数据。不同音色版本、句子长度、首次加载、线程数、内存速度、CPU 功耗限制和游戏负载都会影响结果。

2026-10-13 检查本机确认 CPU 为 9700X。此前运行日志中，克洛琳德短圈速句约 2.6 秒，长状态摘要约 10～13 秒。这些历史数据不是标准跑分，模型切换和运行负载未控制。

缓存命中会直接读取已有音频，避免重新合成。临近车辆、旗号等即时提醒应优先缓存。更换 CPU 不能弥补没有缓存的新句子生成等待。

可使用 `work/race-voices/benchmark.py` 对运行中的服务做同句测试，记录首轮请求与缓存命中延迟。它会生成测试音频但不播放，不改角色分工。

官方性能说明：[GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS)。官方给出的其他硬件及长文本结果不直接适用于本项目的短句播报。
