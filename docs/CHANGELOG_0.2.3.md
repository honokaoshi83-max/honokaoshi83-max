# 0.2.3 更新说明

更新日期：2026-10-14。

- 工程师、观察员和策略师通过共享 Voice Server 排队播放，避免角色介绍和开场状态同时说话。
- 本地赛道播报等待开场语音结束；邻车提醒优先。
- 启动播报时自动启动已配置的 Simulator Controller 和共享语音服务；停止时只关闭助手启动的实例。
- 修复助手插件未启用导致人物介绍不生效的问题，补充退出驾驶提示及固定缓存条目。
- 状态摘要的进站服务统一表述为“当前进站服务：”。
- 圈速播报等待成绩更新，不再在半秒后使用旧成绩。没有新成绩的待播任务五秒后取消，避免出场圈任务串到下一圈。

## 验证情况

99 项后台测试和 16 项桌面测试通过。本机共享语音服务启动、停止及重启已检查，控制器启动参数已指向共享语音服务。

游戏内开场语音、筑波出场圈与连续计时圈仍待验收。动态发车的编队圈与正式圈区分尚未验证。连续两圈成绩完全相同时，目前跳过该圈播报，避免误报旧成绩。另一台设备安装仍待实际验收。

## 安装

升级前停止播报并从托盘退出界面。安装程序与同名 setup-1.bin 保持在同一目录，再运行安装程序。升级保留已有播报按键绑定，首次安装默认无绑定。
