# 0.2.5 更新说明

发布日期：2026-10-15。

## 首次安装与自动启动

- 修复一键安装显示接入成功、却因Simulator Controller尚未生成用户ID而无法自动启动的问题。
- 安装准备与启动前自动建立缺失的本地GUID；保留原有配置ID和数据库ID。只有旧数据库ID时复用它，不需要注册账号或填写iRacing Customer ID。
- 先准备身份，再写入150米慢车范围，最后启动组件；已有更短距离保留。异常既有ID保留原文件并报告错误。
- 升级仍保留个人播报按键绑定；首次安装默认未绑定。模型、音量、轮胎阈值与圈速识别机制保持原设定。

## 播报调整

- 芙宁娜介绍改为：“我是芙宁娜，比赛中的圈速播报和周围赛车提醒由我负责，我也会留意天气变化与进站策略。”避免将“圈速”独立分段；模型和参考录音未改动，实际自然度仍需听感确认。
- 方格旗改为：“方格旗，本次比赛结束，请安全返回。”仍由芙宁娜播报；退出告别继续由克洛琳德播报。
- 可选维修标志持续约2秒、没有强制维修标志时，改为：“检测到车辆碰撞，请安全驾驶。方向、制动或动力异常时提前回站进行维修。”强制维修优先级及维修完成提示保留。
- 前方慢车使用组件原生150米识别范围，不采用先接收远处事件再静音的方法。

## 检查结果与边界

- 157项后台、16项桌面测试通过；另用实际安装目录中的模块通过11项身份及首次安装定向测试。新建基础配置、中文接入、150米设置到启动的组合测试已覆盖，进程创建使用替身。
- 13项模型及基础资源哈希检查通过，446个本机缓存全部可解码；735条名称通过安装引擎的归一化与音素检查。实际EXE完成offscreen启动检查。
- 两条圈速边界继续等待游戏验证：成绩先更新、圈数后更新时可能漏报；连续两圈完全同成绩仍可能跳过。
- 动态天气没有新增独立监测器。组件包含天气与轮胎规则，但iRacing适配器的10／30分钟字段沿用当前天气，不能视为真实预测；雨战换胎、长正赛抢播、全部旗号和另一台设备安装仍待实测。
- 自动检查不能替代实体按键、扬声器听感及真实游戏验收。

## 安装、升级和日志

完整安装版包含Python、CPU PyTorch、GPT-SoVITS和默认双音色。Simulator Controller仍由安装引导联网取得官方组件。升级前停止播报并从托盘退出界面，安装器与配套bin保持同目录。

左侧“诊断日志”显示运行信息。完整日志在安装目录`work/race-voices`，组件安装日志在`logs/simulator-install.log`。源码和安装包不包含个人路径配置、已有ID、按键状态、驾驶日志或自定义音色。
