# 0.2.6 源码更新说明

更新日期：2026-10-16。本次同步源码和文档，未发布新的安装附件。GitHub正式下载安装版仍为0.2.5；既有本地0.2.6测试包也不包含本轮全部最新修改。

## 实时播报按键与安全优先级

- 按键监听与请求分发独立于SDK、复盘和语音推理，取消超过五秒静默丢弃请求的路径。
- 驱动读取异常自动恢复，临时配置写入失败保留最后有效绑定；增加捕获、入队、消费与分发日志。
- 后台繁忙时为手动请求预留队列及HTTP通道，等待中的手动合成优先于普通信息。旧播报取消不会停止新确认音。
- 快车、蓝旗、左右并排、保持线路及净空安全提醒优先于手动摘要，可以打断摘要与确认语音；安全提醒本身不会被按键确认音抢断。
- 安全请求绕过手动等待门控，拥有独立HTTP线程与队列预留位置。等待合成顺序为安全、手动、普通；正在执行的模型调用安全完成，不强杀推理。
- 原生安全语音正在播放时，按键仍可接收，摘要等待；摘要中途被安全提示打断后可再次按键查询。普通信息不会继承上一条安全提醒的优先级。
- 保留原绑定、单次按下和八秒防重复；首次安装仍默认未绑定。

## 自动复盘与评价

- 新增一级“复盘”页面，展示最近一次比赛；历史TXT和JSON全部保留在安装目录“复盘”文件夹。
- 页面表格每行三组字段，整页不滚动。评价区按实际文字由约1:5扩大到最大2:3，超出内容可在评价框内滚动。
- 正赛包含真实日期时间、赛道、车辆、模式、比赛用时或已记录用时、圈速与排名；Time Trial评价圈速、有效圈、犯规及连续表现，不分析排名。练习和排位保持原样。
- 取消保存复盘的询问，保存成功由芙宁娜统一播报“本次复盘已经保存”。
- 有可靠SDK剩余时间时，提前退出后等待预计结束再分析已有数据；等待状态跨重启保留，重连继续采集。退出后实际结果不推断，缺少可靠剩余时间时明确标注退出快照。
- 全部计时圈包含有用时的犯规圈，有效圈另算；无用时犯规圈只计入犯规比例，取消单个无效圈自动降级。
- 波动率＝总体标准差÷平均圈速×100%。不超过0.75%为稳定，超过0.75%且不超过2%为有一定波动，超过2%为不稳定；不足五个计时圈不评级。这是助手参数，不是官方赛事评分。
- 规则紧跟百分比括号显示：“有效计时圈的圈速波动率为1.29%，圈速有一定波动。（0.75%内为稳定；0.75%至2%为有一定波动；超过2%为不稳定）”。括号不朗读，完整公式和精确边界保留于JSON元数据。
- 中位数和MAD仅辅助描述明显慢圈，不删除圈速，不推断原因。语音与文字共用波动率及前后段趋势规则。

详见[复盘说明](REVIEWS.md)。

## 赛事策略（测试中）

- 新增与首页同级的赛事策略页面，可录入赛事、车辆、时长、初始燃油及估算参数，查看初步燃油安排。
- 使用主动开关，默认关闭；不启用时不运行该部分策略计算。
- 这是初步燃油计划与遥测修正模块，不自动修改游戏进站选项，不承诺求解交通、天气、轮胎与换手的综合最优策略。

## 应用内更新

- 侧栏及托盘新增“检查更新”，由用户手动查询固定GitHub仓库的最新正式版本；不是启动时自动查询。
- 优先选择匹配当前版本的EXE增量包，核对HTTPS地址、文件大小与SHA-256后启动更新器。
- 没有匹配增量附件时提供发布页入口，不自动下载完整模型包。
- 替换前验证原文件并备份，异常回滚。个人设置、按键、音量、音色、缓存和复盘保留；已自行修改的程序文件停止覆盖。
- 驾驶会话或其他任务进行中禁止应用更新。更新后恢复此前运行的后台，原来停止的后台不会自动开启。
- 已有0.2.4和0.2.5升级到0.2.6的测试补丁，但尚未根据本轮全部改动重新打包。新设备仍需完整安装环境。

详见[更新使用说明](UPDATES.md)。
