# 0.2.4 更新说明

## 播报与音色

- 芙宁娜负责圈速与快慢对比、周围赛车、天气、旗号和策略；克洛琳德负责车辆、油量、轮胎、维修和通讯摘要。已识别的内容在统一语音入口强制对应音色。
- 开场按固定顺序播放：赛车准备就绪、克洛琳德介绍、芙宁娜介绍、赛道名称、环境状态、通讯按钮说明与祝福。
- 修复优先队列在相同时间戳下按文本排序的问题；旗号插播后保留开场原顺序。退出或切换会话取消旧开场。
- 过滤组件重复开场和拆分的初始状态；普通请求不误标为紧急提醒。保护优先级文件并发写入，警告不被普通请求降级。
- 首页试听使用中性测试句，分别保留所选音色。预热提示采用亮蓝色加粗，首页职责说明已更新。
- 退出提示统一为“本次比赛结束，期待下一次合作”；修复退出配置的Unicode编码、换行与乱码兜底。

## 遥测与中文读法

- 出场圈事故记录按圈隔离，第一有效计时圈可作为第二圈的对比基准。
- 前后车手采用当前会话的真实参赛编号；1号读“一号”，11号读“十一号”。排名不当作车号；已知重名不猜编号。
- 旗号变化时由芙宁娜说明含义，持续同一旗号不重复；黑旗没有具体处罚证据时提示查看屏幕。
- 537条赛道／布局、192条车辆／版本及6个别名已通过中文语音前端检查；筑波2000读“两千”，131圈读“一百三十一圈”。车型代号保留911“九幺幺”、718“七幺八”。
- 补充控制器及语音服务恢复、停止状态与共享服务所有权处理；运行日志、参赛车号快照等本机状态不随安装分发。

## 验证及限制

143项后台、16项桌面测试通过。已有游戏实测确认圈速、出场圈隔离、早期开场顺序和维修播报；最新优先队列排序通过同时间戳与旗号抢占后的恢复回归，尚待再次游戏验收。语音角色路由、旗号及车号代表句已生成有效音频。

仍待验证：长正赛抢播、真实车号与全部旗号触发、未知组件缓存语音的抢占、其他设备安装。成绩先于圈数更新和连续完全同成绩时可能漏报，按用户安排保留等待实测。黑旗具体违规原因不能仅由旗号位推断。

## 安装与升级

完整安装包包含本地Python、CPU PyTorch、GPT-SoVITS及默认双音色。安装结束默认勾选Simulator Controller引导，需联网取得官方组件；已有组件可复用。

升级前停止播报并从托盘退出界面。安装程序与同名setup-1.bin放在同一目录；升级保留已有按键绑定，首次安装默认无绑定。安装后重新启动，赛前可运行固定缓存预热。
