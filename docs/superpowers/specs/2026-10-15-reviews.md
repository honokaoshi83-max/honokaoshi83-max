# 自动复盘与历史记录

按用户直接要求实施。新增一级“复盘”页，显示最近五条，点击在资源管理器选中文本。所有历史文本保存在应用根目录“复盘”文件夹，不删除旧记录。记录真实日期和起止时间（含时区）、赛道布局、车辆、模式、可确认的比赛总用时、记录用时、圈数与评价。

正赛保留现有 Simulator Controller 评价和音色，截取其复盘段落保存。补充总排名、组别排名、车辆数、可用时的发车名次与名次变化。缺失字段写明未知，不把当前圈位置当成官方最终结果。

仅增加 Time Trial 评价，练习和排位不变。最快与平均有效圈速单列；稳定性统计包含犯规无效圈的有效计时，排除出场圈、进站圈、未知计时和断线跳圈。无效圈数量和比例会降低稳定性评价。借用正赛已有 8% 失误提醒阈值作为本地评价界限，不冒充官方 Time Trial 成绩规则。不对比排名，不认定完成官方连续圈要求。

移除保存报告询问与原保存成功语音，使用“本次复盘已经保存。”，仅在文本及索引实际落盘成功后由芙宁娜播报一次。写入失败记录诊断，不误报成功。原有退出告别、开场、圈速、旗号与车辆语音保持。

正赛从既有复盘请求采集，不能另造比赛排名评价；采集通过原始请求事件和合成完成事件，等待末段或静默期结束，避免 TTS 尚在计算就提前结束。Time Trial 从独立的会话记录器采集，不改变原圈速识别器。

真实计时边界只有在观测到比赛进入正式计时阶段后才标记完整；中途接入只给记录时段，整场用时未知。断线保留上下文等待重连，确定结束或换场后输出。重启恢复进度，按会话去重；迟到语音不得归入新场次。

复盘功能独立于策略模块开关。升级保护复盘文件、采集状态和事件日志。当前只更改本地，不发布 GitHub 或重打安装包。
