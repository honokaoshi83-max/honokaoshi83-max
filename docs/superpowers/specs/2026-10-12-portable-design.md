# iracing中文播报助手移植设计

目标：在 Windows 10/11 x64 的新设备上通过双击安装、启动、配置按钮使用；无需复制原设备路径、虚拟环境或私人配置。沿用现有本地提醒和双音色能力，云端对话保持移除。

采用独立目录中的便携 Python 3.10、锁定依赖和管理界面。默认 Windows 中文语音，可选原发布者的 GPT-SoVITS 角色模型；模型不随仓库或压缩包再分发。系统语音不冒充角色音色。Simulator Controller 单独通过官方安装器安装并保存基础配置，本项目在备份之后只调整三个助手的语音路由及中文表达，不替换整体个人配置。

组件：data 保存公共词典、语法和音色下载清单；config 提供默认设置；scripts 负责安装、启动、停止、诊断、配置和发布打包；work/race-voices 保存本地程序；.runtime 保存本机 Python、依赖与下载，全部不入库。通过已知文件夹检测 Documents 与桌面位置。PS 按键可修改设备与按钮编号。

验证：现有行为回归、路径与下载安全、配置保留、干净目录安装、系统语音真实合成与接口、安装包隐私扫描。角色合成使用本机已有受校验资产作隔离验证，并明确没有第二台电脑的完整游戏验收。
