# 音色库与角色替换

用户确认两个角色：工程师、观察员/策略师，每个角色可增加并选择音色。默认克洛琳德和芙宁娜不能删除。

1. 后端音色目录记录固定预设、自定义文件、来源与 SHA256；角色分配与协议音色标识分离。
2. 导入支持本地 GPT/SoVITS/参考录音，以及 Hugging Face 公开仓库文件列表和固定 commit 下载。参考文本必填；不执行仓库脚本。
3. 校验成套权重结构、模型版本、3~10 秒参考音频。首版接受当前运行环境支持的 v1/v2/v2Pro/v2ProPlus；其他版本提示额外组件未适配。
4. 导入不改变当前角色，用户选择后重启语音服务；默认预设不受删除/自定义同名覆盖影响。
5. 删除只处理应用专属自定义目录，删除正在使用音色会恢复对应默认角色。UI 提供音色列表、角色下拉、试听、导入和删除。
6. 本机验证默认保护、角色回退、路径限制、Hugging Face 清单获取、已有模型导入/试听/删除；实体按键验收仍保留。

应用仍需要 GPT-SoVITS/Python/PyTorch 推理环境。用户后续要求完整离线安装，现将便携环境、推理源码、基础模型和默认两音色一同安装到应用目录；不将大型模型编译进界面 EXE。新增完整 Setup 安装程序，本地构建暂不公开分发角色模型。
