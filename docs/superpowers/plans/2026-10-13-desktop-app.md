# 桌面应用首版实施计划

用户要求按已生成的深蓝色界面参考图构建可运行应用，包含点击学习方向盘播报按键。

1. 使用 PySide6 构建五页窗口和托盘，运行概览显示真实游戏/语音/按键状态。
2. 保留语音后端独立运行。首页只读遥测与健康检查，后台操作通过子进程，窗口不被合成阻塞。
3. 绑定页提供开始、取消、30 秒超时；忽略预先按住和重连时按住的按钮，原子保存并热加载。
4. 日志显示实际最近播报，不填示例遥测。音色和诊断页面连接现有工具；暂未实现的控制不冒充可用。
5. 独立 UI 环境打包目录版 EXE，创建桌面快捷方式，测试窗口构建、截图及后端控制。

首版边界：Windows x64；当前 WinMM 按钮学习限前 32 个键；设备编号变动后可重新绑定，不声称有稳定设备 GUID 匹配。显示角色名称和分工，头像首版使用图形标识。Qt 许可与安装说明随发行保留。暂不更改 GitHub 发布，待本机验收。
