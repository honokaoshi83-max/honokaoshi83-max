# PS 键单次状态播报

当前使用原绑定 `1Joy25`（Windows 第一个游戏控制器、第 25 个按钮）。PS 键按下后请求一次摘要，由克洛琳德播报；不录音、不启动对话、不调用云端 API。

## 操作

- 单击一次触发；长按不连发。
- 8 秒冷却；摘要排队或播放中不叠加第二份。
- 启动或重新连接时已经按住的按钮不触发，先松开后再按。
- 不拦截或模拟按钮输入，游戏仍可看到原按键。如果游戏把 PS 键绑定了其他功能，需要在游戏内解除该冲突。
- 方向盘设备顺序改变时，修改 work/race-voices/status_button_settings.json 的 device 编号并重启服务。按键检测状态记录在 status_button_status.json。

## 摘要内容与来源

1. 车辆：实际发动机告警、强制/可选维修标记；停在维修位时读取剩余维修时间。没有告警只说明未检测到标记，不保证车辆无损伤，不播报猜测出的损伤部位。
2. 油量：iRacing SDK 当前 FuelLevel，以升播报。油耗由最近最多五个完整、未经过维修区的圈计算；至少两份有效样本后估算续航。首次接入的半圈、进站圈、加油前后的混合圈不用于油耗计算。加油、退出驾驶和新会话重置历史。
3. 战术：预留一圈油量后的预计完整圈数；基于圈数或时间赛制的燃油到终点估算；必要时提出燃油进站建议。当前版本不求解轮胎、天气、交通、换手和强制进站规则的综合最优策略。
4. 已设置的进站服务：SDK PitSvFlags、PitSvFuel、自动加油选项；播报加油量、换胎数量和快速维修勾选状态。它表示游戏里选中的服务，不表示已经提交或执行了最优策略。单位缺失或无法明确时不猜测具体加油数量。

油量或油耗数据不足时明确说明无法估算，不编造窗口；未连接游戏、回放或未在驾驶状态时提示当前无法读取状态。

## 播报和安全优先级

状态摘要复用现有本地语音服务。动态数字首次合成可能较慢；固定离线提示已预缓存。邻车/旗号等 Simulator Controller 语音开始时摘要让位并停止，不从头重复长摘要。按键扫描每 20 毫秒，游戏数据仍按现有约 250 毫秒周期读取。

此功能只读，不自动选择加油量、换胎或维修选项。当前没有接入 Simulator Controller 的完整优化策略文件，以避免把旧比赛文件误报成当前计划。

## 验证

按键逻辑、油耗样本、维修信息、进站设置和配置清理均有自动测试。实际方向盘 PS 键与游戏内数据播报仍待设备连接后的验收；当前设备未连接，不标记为已通过实体按键测试。

实际本地接口已生成完整测试摘要（合成数据，不是当前游戏状态），首次生成约 22.5 秒，未播放。固定离线提示已预缓存，完整动态摘要的首次等待仍需进一步优化。验证见 PS状态提示验证.json；固定提示缓存已补齐到 199 条。
