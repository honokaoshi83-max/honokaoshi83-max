## 项目目标

在驾驶时提供简洁的中文车内工程师播报，包括圈速、周围赛车、旗号、油量、进站策略、轮胎检查与维修提醒。工程师为克洛琳德，观察员与策略师为芙宁娜，采用纯净音色，减少重复和机械翻译。

基础提醒通过遥测与确定性规则执行。DeepSeek API 仅列为后续计划，当前移除云端对话接入，用于未来可选的对话与策略解释；本地不运行大语言模型。本地 GPT-SoVITS 负责语音合成：工程师为克洛琳德，观察员和策略师为芙宁娜，共用一个引擎串行切换模型。

## 当前架构

```text
iRacing 遥测 ──→ Simulator Controller ──→ 中文语音接口
       └──────→ Python 圈速/赛道/损伤/轮胎检查 ──→ 播报队列
                                           ↓
                                GPT-SoVITS 双音色串行合成

DeepSeek API：当前运行配置已移除，仅保留后续计划
```

Simulator Controller 提供赛事工程师、策略师和观察员框架；Python 补充直接遥测播报。语音接口使用 OpenAI 兼容协议，实际语音由本机服务合成。

## 损伤提示的边界

- 事故积分仅作为事故线索，不据此判断具体损伤程度。
- 以游戏实际提供的维修要求、发动机告警和维修倒计时为依据。
- 按使用需求，不播报具体车身部位，也不推测损伤百分比。
- 维修完成须观察到本次维修过程、倒计时归零及维修服务完成状态；提前离开车位或数据缺失不报完成。
- 维修完成不代表所有不可修复损伤消失，也不自动批准出站。
- 所有提醒只辅助驾驶，不控制赛车或自动操作进站选项。
