# API 对话后续计划（未启用）

当前版本仅运行本地遥测规则、Simulator Controller 基础提醒和 GPT-SoVITS 双音色播报。云端 API 对话已从当前运行配置移除，PS 键专用于状态摘要，不启动麦克风、语音识别或云端对话。

## 后续目标

如以后重新需要对话，使用 DeepSeek 云端 API 解释已确认的遥测事实与策略。基础旗号、邻车、低油量、维修提醒始终由本地规则执行，云端失败不得阻断基础播报。

## 实施步骤

1. 单独建立可选对话模块和明确的开关，默认关闭。不要复用 PS 状态键；另选按键或界面入口。
2. 用户在本机安全输入 API 密钥，不在规划文件、GitHub、日志或音频缓存中保存密钥。
3. 输入只使用当前会话内有效的车辆、油量和计划摘要，明确标记轮胎等进站更新数据；不将缺失字段猜成正常。
4. 为请求增加超时、限流、有限重试和断路保护。错误只提示一次，恢复后解除；不反复播报连接失败。
5. 回答保持简短中文，由指定角色播报。队列让位于邻车及旗号提醒，过期回答丢弃。
6. 首阶段只读解释，不允许模型修改进站选项、赛车设置或控制赛车。进站建议须区分计算建议和已设置的服务。
7. 验收断网、密钥失效、长时比赛、摘要过期和开关行为，再考虑开放。

## 当前移除范围

- 清空当前 Simulator Configuration.ini 的 Conversation Booster、Agent Booster、Driving Coach Service 和 Driving Coach Conversations 配置。
- 关闭全局语音监听，清空 PushToTalk 绑定。
- 原“接入DeepSeek.ps1”部署入口已改为停用说明，不再读取密钥或发送请求。
- 保留本地 `127.0.0.1:9881` 语音协议接口。其 OpenAI 字样仅表示兼容协议，不是云端对话。
- 历史配置备份保留用于恢复，可能包含旧凭据，不应上传或共享。当前配置中不保留云端对话凭据。

本计划不构成已经部署或已经验收的 API 对话功能。将来启用前重新确认范围和成本。
