# 双音色播报节奏与情绪配置

当前已接入三档场景路由：平稳 calm、警告 warning、鼓励 encouraging。默认请求 emotion=auto，Simulator Controller 和 SDK 提示无需更改即可使用；也可以在语音 API 中明确指定档位。

## 当前实际效果

- 平稳：保持原语音。
- 警告：语速提高 4%，不改变音高，不添加通讯器效果。
- 鼓励：语速提高 2%，保持轻微节奏变化。
- 保留现有双角色模型和 -16 LUFS 纯净音量处理。没有增加常驻模型。

**目前每个角色仅有一条原始参考录音，因此这次部署是节奏优化和情绪路由基础，不代表已经合成出可靠的坚定、喜悦等情绪。真正的情绪改善仍需合适的角色参考录音并试听验收。** 不使用提高 temperature 冒充情绪控制，也不从合成音反复克隆参考素材。

警告优先于鼓励。黄旗解除、维修完成、普通圈速保持平稳；前后车和领跑车刷新最快圈不触发鼓励。分类依据播报文本规则，不调用 DeepSeek，不增加网络请求；自由文本可能需要继续补充规则。

## 缓存和性能

没有情绪参考时复用已有原始缓存，通过 ffmpeg 的 atempo 进行小幅节奏调整；各档结果单独缓存。缓存命中直接返回。新参考录音首次生成仍可能较慢，应在比赛前预热。

运行 work/race-voices/warm_cache.py 可缓存固定提示的自动档位。work/race-voices/verify_emotions.py 生成两位角色各三档同文本对比文件到本目录的“情绪试听”文件夹，程序仅验证音频、时长和重复缓存，不自动播放，也不代替实际听感验收。

## 增加真实情绪参考

修改 work/race-voices/emotion_settings.json，在 voices 下增加对应角色的档位，例如：

```json
"clorinde": {
  "warning": {
    "reference": "models/clorinde/emotions/warning.wav",
    "reference_text": "这里填写参考录音实际说出的完整原文。"
  }
}
```

参考路径相对于 work/race-voices；音频必须是目标角色本人、清晰无背景音乐，文字必须对应原录音，不能填“紧张地说”等指令。缺少文件或文字时自动回退到原始音色的节奏调整。新增或修改配置后重新启动语音服务，再预热缓存。参考内容、文字或档位速度变化会产生独立缓存。

平稳档目前直接使用原始参考；可分别给 warning 和 encouraging 配置真实参考。语速限定在 0.95–1.08。当前规则只改变表达，不更改提醒阈值、消息内容和维修策略。
