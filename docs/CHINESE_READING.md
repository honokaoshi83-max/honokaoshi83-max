# 中文读音与数字读法

更新日期：2026-10-14。处理位于语音接口与 GPT-SoVITS 中文前端，不重新训练模型。

## 修正规则

- 筑波固定为 zhù bō。真实中文前端输出为 `zh u4 b o1`。
- 筑波2000、筑波赛道2000布局 → 筑波两千、筑波赛道两千布局。
- 还可以跑131圈 → 还可以跑一百三十一圈。
- 20.5升 → 二十点五升；186千帕 → 一百八十六千帕；-2.5度 → 负二点五度；70% → 百分之七十。
- 2009版 → 二零零九版；年份按位读，赛道布局编号100/200/300/1000/2000按数值读。
- 车型代号和车号逐位读，数字1读“幺”：保时捷911→九幺幺、718→七幺八、车号11→幺幺；64号赛车→六四号赛车。
- 数量仍按自然数读，年份仍按年份逐位读；版本0.2.3不套用数量转换。

名称检查范围为537条赛道/布局、192条车辆/版本，以及6个常用别名。238条明确拼音词组覆盖基准名称与易错词组，包括筑波、长滩、俱乐部、还可以、更换。仅匹配词组，不把“归还”的还改为hái。逐条结果见[名称读法核对表](名称读法核对表.csv)。

“筑”的简体词义有zhù/zhú两种读法，筑波按用户指定的zhù处理：[汉典](https://zdic.net/hans/筑)。柏林采用bó lín：[教育部辞典](https://dict.revised.moe.edu.tw/dictView.jsp?ID=13088&la=0&powerMode=0)。

## 缓存与验证

新数字文本自动形成新缓存键。含读音词典的文本增加读法版本标识，避免继续播放旧的错误读音缓存；无关缓存保留。

118项后台测试覆盖数量、布局、年份、编号、上下文多音字、真实语音接口入口及旧缓存失效。735条完整名称实际通过GPT-SoVITS中文前端，失败0条。两个默认音色已生成非空有效WAV；最终音色发音、声调和听感仍需用户试听，不宣称全部汉字均已通过声学验收。
