# 0.2.1 更新说明

更新日期：2026-10-13。

## 桌面界面

- 首页集成播报设置与实时播报按键，精简说明和间距。
- “Simulator Controller 安装引导”位于首页中部，保留整行入口。
- “预热固定缓存”移至首页并突出显示，说明用途与赛前使用方式。
- 更新浅蓝主题、无系统白边框窗口和应用图标。
- 两个角色独立选择音色；默认音色不可删除，自定义音色可导入、替换或删除。

## 安装与稳定性

- 完整安装版包含 Python、CPU PyTorch、GPT-SoVITS、基础模型及默认双音色。
- 安装完成页默认勾选 Simulator Controller 一键安装并接入，说明取消后的功能缺失。
- 引导隐藏日志框，改为 1%～100% 模拟进度；任务未结束时最多显示 99%。
- 修复安装任务结束回调与窗口信号重名造成的状态不刷新。
- 任务成功后提示重新检测、重启助手；诊断日志保存为文件。
- 修复 WAV 数据头导致测试只响系统提示音的问题。

## 验证边界

界面检查、安装状态读取、模拟进度、真实子进程成功／失败、缓存入口条件和 EXE 启动已验证。实体方向盘按钮、长时间比赛、完整游戏场景及另一台设备安装仍待用户验收。模拟进度不表示实际下载字节比例。

源码不包含 API 密钥、本机配置、运行日志或模型权重；模型完整版通过安装发布附件单独提供，来源与许可见第三方说明。
