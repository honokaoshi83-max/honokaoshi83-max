# 本机待验收更新

更新日期：2026-10-14。

本页记录本机已部署的更新及测试结果。本次仅同步说明和检查记录，相关代码尚未随本次提交上传；安装包暂不更新，等待用户游戏内测试后再发布。

## 播报与服务

- 工程师与观察员／策略师通过共享语音服务排队，减少同时说话；开场状态等待人物介绍结束。
- 启动播报时自动启动已配置的 Simulator Controller，停止时仅关闭助手拥有的服务实例。
- 补充控制器与语音服务恢复逻辑、停止状态记录、开场和退出缓存。
- 进站摘要统一表述为“当前进站服务：加油……、更换……、快速维修”。

## 圈速

完成圈数更新后，等待有效的新成绩，五秒内没有新成绩则取消待播，避免把出场圈或旧成绩报成当前圈。

待验收边界：成绩先更新、圈数后更新时可能漏报；连续完全相同的成绩仍会跳过。前者已用模拟数据复现，尚未确认游戏实际采用该顺序。不得把自动测试通过视为这两个边界已解决。

## 中文读音

- 覆盖537条赛道／布局、192条车辆／版本和6个常用别名，共735条名称。
- 筑波按用户指定的zhù bō读；筑波2000读“筑波两千”。
- 车型代号和车号中的1读“幺”：911读“九幺幺”，718读“七幺八”，车号11读“幺幺”。
- 数量按数值读：131圈读“一百三十一圈”，20.5升读“二十点五升”。年份保持逐位读，如1934款读“一九三四款”。
- 增加238条明确拼音词组；Indy Pro 2000按级别读“两千”。
