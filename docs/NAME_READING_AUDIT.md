## 数字及字母

- 数量与测量值：131圈→一百三十一圈，20.5升→二十点五升。
- 赛道布局：筑波2000→筑波两千；100/200/300等布局按数值读。
- 年份：2009版→二零零九版。
- 型号标识里的数字1统一读“幺”：保时捷911→九幺幺、718→七幺八，福特F150→艾弗幺五零；车号11→十一。其他数字仍逐位读，如992.2→九九二点二；宝马M2→艾姆二，GT3→吉提三。
- 数量和年份不按车号处理：131圈→一百三十一圈，1934款→一九三四款，2018版→二零一八版。
- 路特斯49/79、奥迪90单独采用四十九/七十九/九十；方程式2000、Indy Pro 2000和FF1600读两千/两千/一千六百。
- 英文名称映射到确定的中文/字母读法，不直接把英文交给全中文合成前端。
- 名称库外的车号使用单独的数值读法规则；版本号保留原有上下文规则。
