# PS 按键状态摘要

按一次绑定按钮，播报一次当前状态。长按不连续播报。

首次安装没有默认绑定，需在首页点击“绑定播报按键”自行设置。升级保留已有按键。

按键请求被接受后，先播放本地缓存的克洛琳德提示：“正在整理具体数据，即将开始播报。”随后合成并播放状态摘要。提示不调用 API，随播报音量调整；摘要仍在处理时重复按键不连播。邻车播报正在进行时优先保留邻车提示。固定缓存预热也会更新这条提示音频。

只报告实际数据和已有进站设置。没有进站计划、油耗样本不足时，略过相应部分，不说“没有策略方案”或“油耗样本不足”。

示例：

- 无告警、无进站计划：车辆无告警。剩余油量二十升。
- 有练习圈油耗估算：车辆无告警。剩余油量二十升。预计还能跑九圈。
- 比赛中需要补油：车辆无告警。剩余油量二十升。建议九圈内进站加油。
- 油量足够完赛：车辆无告警。剩余油量二十升。油量够到终点。
- 需要维修：需要强制维修，请安全进站。剩余油量十升。
- 已选择进站服务：车辆无告警。剩余油量十升。进站：加油二十升、更换四条轮胎。

续航仍在计算中预留一圈备用油量，摘要不重复说明计算过程。维修时间只在维修位并有有效剩余时间时报告。未勾选的服务、无法读取的进站选项不播报。

车辆告警或油量数据无法读取时保留简短说明，避免把缺失数据说成正常。未连接驾驶会话时只说“未连接驾驶会话，状态暂不可用。”
