# 0.2.2 更新说明

更新日期：2026-10-13。

- 播报键请求被接受后，立即播放克洛琳德的本地缓存提示：“正在整理具体数据，即将开始播报。”
- 提示音频随完整安装包提供，播放时不调用 API、不运行语音合成。
- 状态摘要仍正常生成；提前生成完成的摘要也会等确认提示结束后再播放。
- 处理中的重复按键和队列已满的请求不会连播确认提示；已有按键冷却、长按防连发和邻车优先逻辑保留。
- 提示随助手播报音量调整；首页“预热固定缓存”也会更新这条提示。
- 固定语音组合增加到 200 条，芙宁娜 120 条、克洛琳德 80 条。
- 首次安装的播报键默认为未绑定；首页点击“绑定播报按键”后自行设置。升级保留已有绑定，不会重置为未绑定。

本机缓存提示启动调用实测约 4.6 毫秒，音频时长约 3.6 秒；这不等于扬声器实际出声延迟。桌面 15 项检查、后台 92 项测试通过，实体方向盘按键与另一台设备仍待用户验收。

此版本保留 0.2.1 的精简首页、首页中部安装引导、模拟安装进度、双角色音色管理和完整本地语音环境。

升级前停止播报，并从托盘菜单退出助手界面。安装后重新启动，使新按键逻辑生效。
