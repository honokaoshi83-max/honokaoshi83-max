## 正在进行：iRacing 中文 AI 赛事工程师

面向个人驾驶的中文车内工程师：芙宁娜语音、每圈报时、赛道名称、过车提示，以及事故与维修提醒。基于 Simulator Controller、pyirsdk 和 GPT-SoVITS；DeepSeek API 用于后续云端对话与策略解释。

- 基础语音、圈速和部分赛道播报已完成游戏测试。
- 开场去重、过车措辞与维修提示已完成本地验证，正在等待游戏场景验收。
- 当前 37 项自动检查通过；下一步重点为服务自动恢复和耐力赛稳定性。
- 云端语音对话目前暂停，先完善基础自动播报。
